## Voucher pictures

`public/assets/voucher-<brand>.webp` is the picture on each brand's voucher (`Voucher` in `src/components/ticket.tsx`):
what the voucher buys, on the brand's colour. They were generated with ChatGPT's image generation on 2026-11-21,
one conversation for all six so the style matches, and contain no text, logos or brand marks; the logo on a voucher
is the SVG above, set on top in code. The generated files are `assets-src/originals/voucher-<brand>.webp`
(1536×1024). Each web file is its original with the background carried 512px further left, which keeps the lower
left clear for the logo and makes the picture 2:1, the shape of the space on the card.
